# Atividade-Desenvolvimento-Web
O presente trabalho tem como objetivo o desenvolvimento de um website para uma confeitaria artesanal especializada na produção de bolos, tortas, cupcakes, doces finos e produtos personalizados para diferentes ocasiões. A proposta consiste na criação de uma plataforma digital que permita apresentar a empresa, divulgar seus produtos e fortalecer sua presença no ambiente online. 

O website será desenvolvido com foco na organização das informações e na experiência do usuário, disponibilizando páginas institucionais, catálogo de produtos, depoimentos de clientes, informações de contato e uma área destinada à solicitação de orçamentos. Além disso, o sistema contará com funcionalidades relacionadas ao cadastro e autenticação de usuários, permitindo que determinadas operações sejam acessadas apenas por clientes identificados. 

Desta forma, a solução proposta busca atender às necessidades de divulgação, comunicação e relacionamento com clientes, oferecendo uma interface moderna, intuitiva e responsiva.
